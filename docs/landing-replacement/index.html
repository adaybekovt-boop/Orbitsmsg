Orbits

Личные чаты идут напрямую между устройствами и закрыты X3DH + Double Ratchet. Чтобы устройства нашли друг друга, клиент использует сигналинг PeerJS (*.peerjs.com) и публичный STUN (Google / Mozilla / Twilio). Это не «мессенджер без серверов».

Комнаты без сквозного шифрования: организатор видит текст, файлы и стикеры. DTLS защищает только hop до хоста.
